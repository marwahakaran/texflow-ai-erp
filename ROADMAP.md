# Roadmap

This ROADMAP documents features and modules for TexFlow AI ERP.

Modules and features:

- Fabric Composition (multi-blend)
- Fabrication Orders
- Fabric Remnant & Leftover Management
- Style Groups
- Merchant Assignment
- Buyer TNA Email Automation
- Job Work Factory Management
- Material Issue & Return
- Factory Performance Dashboard
- AI Assistant
- Workflow Builder
- Digital Product Passport
- Activity Timeline
- Visual Production Board
- Fabric Reservation Engine
- Barcode/QR Roll Tracking

Epics & initial backlog items should be created as issues and added to the project board.
